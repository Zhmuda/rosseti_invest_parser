# Парсер приказов по ИПР ПАО «Россети»

`parse_rosseti_ipr_orders.py` получает компании и документы через API Минэнерго, находит документ `Приказ Минэнерго России` по дате публикации и скачивает его.

Запуск:

```bash
python3 parse_rosseti_ipr_orders.py
```

Скрипт печатает в консоль компанию, тикер, дату публикации, название, ссылку и путь к скачанному документу.

Документы сохраняются в `data/rosseti_ipr_orders/`.

Для другого года:

```bash
python3 parse_rosseti_ipr_orders.py --year 2025
```

Распаковать ZIP, найти Excel и отправить его содержимое в YandexGPT:

```bash
python3 parse_rosseti_ipr_orders.py --year 2025 --company pao_rosseti_severnyy_kavkaz --analyze
```

Только проверить, что извлечены все листы и текст Excel, без отправки в ИИ:

```bash
python3 parse_rosseti_ipr_orders.py --year 2025 --company pao_rosseti_severnyy_kavkaz --print-excel
```

Ключи `YANDEX_AI_KEY` и `YANDEX_CLOUD_FOLDER` автоматически читаются из `../smart_home_service/.env`. Excel-файлы распаковываются в `data/rosseti_ipr_orders/extracted/`, ответ сохраняется рядом с ними в формате `.analysis.md`.

## Мониторинг новых документов «Россети Волга»

`rosseti_source_monitor.py` проверяет по два источника для каждой подключенной компании:

- РСБУ: с 10 октября по 10 ноября ищет «Бухгалтерская отчетность за 3 квартал YYYY года»;
- Минэнерго: с 10 по 31 декабря ищет приказ по инвестиционной программе за YYYY год.
- Минэнерго для «Россети Центр»: с 10 по 31 декабря ищет приказ по инвестиционной программе за YYYY год.
- «Россети Центр»: с 10 октября по 10 ноября ищет бухгалтерскую отчетность за 9 месяцев YYYY года на сайте mrsk-1.ru.
- «Россети Московский регион»: с 10 октября по 10 ноября ищет промежуточную бухгалтерскую отчетность за 9 месяцев YYYY года в реестре e-disclosure.
- «Россети Северо-Запад»: с 10 октября по 10 ноября ищет бухгалтерскую (финансовую) отчетность за 9 месяцев YYYY года на сайте rosseti-sz.ru.
- «Россети Ленэнерго»: с 10 октября по 10 ноября ищет бухгалтерскую отчетность за январь–сентябрь YYYY года на сайте rosseti-lenenergo.ru.
- «Россети Юг»: с 10 октября по 10 ноября ищет бухгалтерскую (финансовую) отчетность за январь–сентябрь YYYY года на сайте rosseti-yug.ru.

Для приказов используются декабрьские окна. После обнаружения документа монитор отправляет файл, дату публикации и котировки MOEX: текущую цену и закрытие предыдущего торгового дня. Для каждого источника год хранится отдельно и увеличивается на единицу только после нажатия кнопки остановки.

При обнаружении РСБУ-PDF отправляется в Telegram как есть. Из ZIP Минэнерго извлекаются и отправляются только Excel-файлы; сам ZIP и остальные файлы не сохраняются. После нажатия кнопки остановки удаляются все файлы, сохранённые монитором для выбранного источника. Состояние и текущий год хранятся в SQLite.

Запуск без Docker:

```bash
python3 rossetti_source_monitor.py
```

Docker Compose использует локальный `.env` этого проекта:

```bash
docker compose up -d --build
docker compose logs -f
```

По умолчанию используются `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Для одновременной работы с KHL-ботом рекомендуется отдельный Telegram-бот:

```dotenv
ROSSETI_TELEGRAM_BOT_TOKEN=...
ROSSETI_TELEGRAM_CHAT_ID=...
```

Источники сначала проверяются напрямую, а при ошибке доступа запрос повторяется через прокси. Telegram использует прокси всегда. Проверки выполняются каждый час с 07:00 до 00:00 по Москве; ночью источники не опрашиваются. После успешной отправки файл удаляется сразу. Для ручного изменения интервала задайте `ROSSETI_POLL_SECONDS` в `.env`.

Разовая проверка отчёта «Россети Центр» за 9 месяцев 2025 года:

```bash
python3 rosseti_source_monitor.py --once --source rsbu_center --year 2025 --download-only
```

Файл сохранится в `data/rosseti_ipr_orders/monitor/rsbu_center/`.

Поддерживаемые тикеры для карточек Минэнерго и котировок MOEX: `FEES`, `MRKC`, `MRKV`, `MRKU`, `MSRS`, `MRKZ`, `LSNG`, `LSNGP`, `MRKP`, `MRKS`, `MRKY`. `LSNG` и `LSNGP` используют одну карточку ПАО «Россети Ленэнерго», но котировки запрашиваются по выбранному тикеру.
